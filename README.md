# Projects Repo

## Description
 
Hello world and welcome to my projects repo! This is my public repo for uploading and documenting the progress I make with various projects as a Cloud Systems Admin. Most of these projects will be simple scripts for day to day tasks but I will also upload larger scale
projects including various versions of code as a way to show progress as things either scale or continue to develop. 

## Disclaimer!

These are real world scripts that I have developed and used in production environments so prior to uploading all code has been santized to remove any sensitive information.

## Executing 

* Some code required depencies or libraries to be installed. Not all code will have those installation commands as part of the script but I will do my best to include those as I continue to grow this repo
* All code has been sanitized to remove any sensitive data or information. Feel free to use the code as you see fit but remember to replace any missing information to work in your environment
* All code has been tested and used in a production environment. This is not saying that each script has been maintained thoroughly. Keep in mind that things could have changed
* Check the versions! Some projects have various versions of the code that was used to continue to scale the project. Not all versions will be applicable to all environments. Please review them prior to use
